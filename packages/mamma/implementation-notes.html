Decisions & deviations

DEVIATION Vendored sam2 fork is trimmed, not pristine

Removed demo/, notebooks/, sav_dataset/, assets/, training/, tools/, docker files (~65 MB → 720 KB). No Python in sam2/ itself was touched, so "code modifications: none" still holds. Recorded in packages/sam2-streaming/VENDOR.md. Rationale: repo size; those trees are unused by the pipeline.

DECISION Checkpoint keys kept verbatim; optimizer state dropped

The 1.6 GB Lightning ckpt is mostly optimizer state — the state_dict alone is 0.54 GB (weights_only=True fails to unpickle; conversion ran weights_only=False inside the frozen original env, see tools/convert_ckpt.py). Keys keep their original names (backbone.*, decoder.*, mask_downscaling.*) so the ported module mirrors the original attribute names instead of inventing a renaming map. The monorepo never imports pytorch-lightning.

DECISION sam2 fork API notes for M2

SAM2Prompt takes points_coords/points_labels/boxes/masks_logits (not points); box prompts are [N,4] tensors. Counter helpers on the memory bank differ slightly from the research notes (e.g. non_conditional_memories) — check attribute names against the vendored source, not the notes.

TRADEOFF EfficientTAM variants staged but sam2.1_hiera_small is the M2 default

Uploaded efficienttam_{ti,s}.pt as M6 perf levers (the fork's EfficientTAM configs only work via build_sam2_generic*). Starting tracking quality work on sam2.1_hiera_small, which the original ma_masks used, keeps M2 visually comparable to golden masks before any speed-driven swap.

OPEN HF upload blocked by sandbox — needs Pablo

The private repo pablovela5620/mamma-streaming-data exists, the 2.7 GB tree is staged at /tmp/mamma-hf-stage (with provenance README: golden = baseline run @ optimize-10x commit a912ded), but Claude's sandbox classifier denies the bulk upload of license-gated data. Run: hf upload pablovela5620/mamma-streaming-data /tmp/mamma-hf-stage . --repo-type dataset. Local packages/mamma/data/ is already populated, so nothing downstream is blocked on this machine.

DECISION Dataset/weight redistribution stance

MAMMA data + MammaNet weights are account-gated (MPI-IS license); SMPL-X likewise. Everything goes to ONE private HF dataset repo. Nothing license-gated lands in git. Public checkpoints (YOLO12x, SAM2.1, EfficientTAM) are mirrored in the same private repo purely for reproducible setup.
