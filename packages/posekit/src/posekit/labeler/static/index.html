    Wwatch: play the 5 fps grid from here at 5 frames/s with the machine boxes; W or Space stops (any other key or a click stops too)
    Aaccept the watched run (from the last accept, or where you started, to here): the machine boxes become labels. Still playing or at the end: up to this frame. Stopped: up to the frame before this one; fix this frame, Enter, then W again
    Shift+Aaccept the watched run including this frame
    L / R*set the side of the selected box (*R with no box selected = range fill)
    Delremove the selected box (that side becomes no_hand)
    Faccept the whole frame set as shown (sides without a box = no_hand); was A before the watch loop
    Xreject the focused camera (cannot be judged); again to undo
    Entersave the frame set (the machine track is recomputed from it)
    Nnext queue item
    Shift+Rrange fill from the previous reviewed keyframe to this one
