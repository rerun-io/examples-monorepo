Section 1

The decisions, first

Settled in the interview. Hover a card for the fine print.

  1. One package: packages/dataforge/ Future home for all dataset work. v1 ports exactly two simplecv datasets: robocap + HOCap.
  2. Four verbs: download → convert → register → view. Train + eval are the reserved second half.
  3. Registration idiom: unchanged. Adding a dataset = one import + one dict line.
  4. Chunk-native conversion. No per-frame rr.log loops. The .rrd is the baseline artifact.
  5. Team artifact convention. One base .rrd per sequence; derived layers (GT included) share the recording_id; layer-major on disk.
  6. simplecv is the base · catalog optional · one shared schema dataforge:v1 in stdlib-only schema.py + paths.py.

Why conversion changes: the logging SDK vs the chunk API

Every rr.log call builds one tiny row-chunk — the bloat the team fought in the POC. The chunk path writes columnar once.

Two conversion paths
Same input, same recording — different write mechanics. dataforge takes the lower lane; rr.log survives only for one-off statics (calibration, meshes, annotation contexts).

Section 5

What each system taught us

What dataforge copies and refuses. Citations are file:line in the studied repo; full findings at /tmp/dataflow-research/results/.

simplecv exoego packages/simplecv

The donor: 11 datasets, one rig schema, 13.8k LOC.

Adopt

  • The dict → tyro registry, composable by dict-merge. exoego_dataset_configs.py:21
  • SequenceIdentity: one value → key, recording_id, path. sequence_identity.py:36
  • Enumeration classmethods: free --dry-run, resume, progress. base_exoego.py:534
  • Rig layout derived from camera data, not per-dataset code. base_exoego.py:314

Avoid

  • The exo/ego class split — 842 LOC per dataset.
  • A writer with no reader.
  • Per-frame rr.log convert; silent 5-item cap; 719 LOC dead code.

egoexo-forge packages/egoexo-forge

Being replaced: ~360 live LOC of viewer glue.

Adopt

  • Nothing unique — its registry idiom lives in simplecv (decision 3).

Avoid

  • Deprecation-by-stub; a 490-LOC dead fork that lints green.
  • Broken subcommand in --help; CUDA env for an iframe; no CI.

robocap-slam packages/robocap-slam

A consumer, not a dataset: cuVSLAM over the simplecv robocap loader. Studied as the simplicity baseline (1,452 LOC).

Adopt

  • Self-bootstrapping download task (outputs= + depends-on). pixi.toml:1163
  • Nested RerunTyroConfig; field docstrings as --help; 10-line shims.
  • Reference-rrd regression diff as an eval gate. rrd_compare.py:317

Avoid

  • Skipping conversion entirely.
  • An ABC shaped around one consumer; /tmp eval baselines.

arkitscenes-download packages/arkitscenes-download

Most modern in-house package: 4 verbs, layers, catalog, 4,228 LOC.

Adopt

  • Module-per-verb: Config + main + 5-line shim. No framework.
  • Stdlib-only schema.py/paths.py contracts, pinned by a test.
  • atomic_recording (26 lines). ingest/recording.py
  • Zero-copy sub-datasets from filtered segment tables. ingest/subdataset.py
  • Typed properties as the query surface; subprocess-per-item batch runner.

Avoid

  • Two on-disk layouts behind auto-detection.
  • 8 raw layer files per capture → 40k fds.
  • Monolithic ingest fn; forked lanes to try an API.

trossen-oss rerun-io/trossen-oss · rerun.io/learn

The official experiment loop; the only system that trains from the catalog.

Adopt

  • Base vs derived layers sharing one recording_id. preprocessing.py:280
  • Idempotent re-registration (REPLACE + --no-recreate); blueprint shipped as data.
  • Split = a catalog query; runs registered in a _runs dataset. train.py:66

Avoid

  • No dataset abstraction at all.
  • Component ids as magic strings everywhere.

abc-130k-conversion rerun-io/abc-130k-conversion

The scale playbook: 130k episodes, >1 TB, 1,752 LOC, no framework.

Adopt

  • Content-derived id = filename = S3 key = segment id. episode_index.py:36
  • Two-level idempotency; zero-byte output = not done; --limit means "N more".
  • Listing cached on repo sha; probe pass over config matrix; closed-GOP re-encode. convert.py:224

Avoid

  • No retries, no failure record at 130k items.
  • Dataset identity smeared across five files; id derived twice.

VSLAM-LAB VSLAM-LAB/VSLAM-LAB

40 datasets, one CLI — the download→convert structure, untyped.

Adopt

  • One tiny normalized IR per sequence — dataforge makes it the .rrd. DatasetVSLAMLAB.py:101
  • Independently-callable stage hooks; completion markers; never mutate the canonical sequence.
  • Missing-data resolution: auto-fixable vs needs-a-human, fix printed. DatasetVSLAMLAB_issues.py:92

Avoid

  • Dicts of lambdas + a sys.argv if-chain.
  • Prose as the type system; no tests; Rerun bolted on.

nerfstudio nerfstudio-project/nerfstudio

47.6k LOC — studied for the registry idiom and the data regrets.

Adopt

  • InstantiateConfig + dict-of-instances registry — already ours, kept. base_config.py:46
  • Nested registries as typed fields → free nested subcommands.
  • "Not installed" stubs visible in --help — right shape for gated datasets. download_data.py:556

Avoid

  • Four registration channels merged by overwrite.
  • Pickled-YAML configs; three unrelated registries (8/15 parsers lack downloaders).

The dataset spec, sketched

Same idiom as today; the only new obligations: per-verb methods, chunk streams.

# dataforge/datasets/hocap.py
@dataclass
class HocapConfig(DataforgeDatasetConfig):
    _target: type = field(default_factory=lambda: HocapDataset)
    subset: tuple[str, ...] = ("subject_1",)     # small fetch by default
    fetch_all: bool = False                      # --fetch-all opts into the corpus

class HocapDataset(DataforgeDataset):
    def download(self) -> None: ...              # transports.hf_fetch + completion marker
    def sequences(self) -> Iterable[SequenceIdentity]: ...
    def base_stream(self, seq) -> LazyChunkStream: ...
        # Mp4Reader re-mux + rig transforms + pinholes + properties + blueprint
    def layer_streams(self, seq) -> dict[str, LazyChunkStream]:
        return {"gt": self._gt_stream(seq)}      # MANO + keypoints as a layer

# dataforge/datasets/__init__.py — the whole registry
dataset_defaults: dict[str, DataforgeDatasetConfig] = {
    "robocap": RobocapConfig(),
    "hocap": HocapConfig(),
}

What convert produces

One sequence on disk and in the catalog
Layer-major files; the shared recording_id is the only glue. The catalog stacks the files into one segment; a missing optional layer is a first-class "not available", never an error.

Section 7

Order of attack

Ranked by value per unit of work; each step ships alone.

  1. Scaffold packages/dataforge/ feature + envs + pyrefly ×3 + .envrc. Copy the feature shape from mv-api.
  2. Contracts first — schema.py · paths.py · identity.py · writing.py · transports.py, unit-tested without data.
  3. robocap (the simplecv dataset) end-to-end — the walking skeleton every dataset copies. Pixel-verify in the viewer.
  4. HOCap + gt layer — proves layers and shared recording_id.
  5. register + view verbs — idempotent, with a per-segment layer-completeness check.
  6. Batch runner — subprocess per sequence, bounded pool, per-item summary.
  7. Migrations, one at a time — exoego datasets → arkitscenes → robocap-slam switch → SLAM sets. Delete donor code in the same PR.
  8. Second half — dataloader lane, splits, pred layers + metrics, runs-as-segments.
Done = pixi run dataforge-download hocap && dataforge-convert hocap && dataforge-view hocap on a fresh checkout; every step re-runnable and crash-safe; viewer output pixel-verified.
