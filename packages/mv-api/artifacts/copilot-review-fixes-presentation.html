All 18 Issues

Use the filters to scan fixed issues, documented choices, and no-change resolutions.

1. Selected detection cameras were only applied to projection matrices

Fixed

packages/mv-api/src/mv_api/multiview_pose_estimator.py

Why it mattered
cams_for_detection_idx filtered pall but not images or pinholes, so tracking could index the wrong bbox or go out of bounds.
Fix
Build one selected-view list and filter bgr_list, pinhole_list, and projection matrices together. Logging still uses the original view index.
Test
Added a fake tracker test proving only the selected camera image reaches the pose model.

2. Verbose 2D logging hardcodes the exo entity path

No code change

packages/mv-api/src/mv_api/multiview_pose_estimator.py

Assessment
The helper is private to MultiviewBodyTracker, which only logs exo multiview detections. Ego/WiLor logging happens elsewhere with ego log paths.
Resolution
Replied on GitHub and resolved. If this helper becomes shared later, it should take an explicit parent log path then.

3. WiLor KeypointResults branch could remain float64

Fixed

packages/mv-api/src/mv_api/multiview_pose_estimator.py

Why it mattered
The code annotated Float32, but one branch reused raw output and relied on NumPy assignment to downcast later.
Fix
Normalize both WiLor output branches through np.asarray(..., dtype=np.float32).

4. Node layer depended on private pipeline helpers

Fixed

packages/mv-api/src/mv_api/api/exoego_nodes.py

Why it mattered
The node API was calling underscore-prefixed functions that had become part of its required integration surface.
Fix
Promoted send_scene_blueprint and run_model_backed_pipeline to public helpers and updated call sites/tests.

5. Synced-video root silently defaulted to current directory

Fixed

packages/mv-api/src/mv_api/data/synced_videos.py

Why it mattered
A missing --root-directory could glob from the wrong working directory and fail unclearly.
Fix
Changed the default to None and raise a targeted ValueError during setup.
Test
Updated the dataset config test to assert the explicit error path.

6. Ego frame sampling used a different reader API

Fixed

packages/mv-api/src/mv_api/data/synced_videos.py

Why it mattered
The rest of the pipeline uses reader[frame_idx]; get_frame would fail on readers that only implement indexing.
Fix
Use reader[frame_idx] consistently.
Test
Added a getitem-only fake ego reader test.

7. Reannotated height/width in one function scope

Fixed

packages/mv-api/src/mv_api/api/full_exoego_pipeline.py

Why it mattered
Some static checkers flag repeated annotated assignments in a shared Python function scope.
Fix
Renamed the per-image locals to image_height and image_width.

8. New public config field had a typo

Fixed

packages/mv-api/src/mv_api/api/full_exoego_pipeline.py

Why it mattered
calib_confg would become part of the Tyro CLI even though this package has no legacy compatibility burden yet.
Fix
Renamed to calib_config and updated tests/validation tooling.

9. Progress iterator ignored max_frames

Fixed

packages/mv-api/src/mv_api/api/full_exoego_pipeline.py

Why it mattered
The progress bar total could say a short run while the iterable still covered the whole video.
Fix
Slice the timestamp array first: timestamps_to_process = shortest_timestamp[:total].

pixi.toml

12. Package dependencies rely on Pixi workspace sources

Fixed

packages/mv-api/README.md

Why it mattered
monopriors, wilor-nano, and rtmlib are resolved by root Pixi sources, not standalone PyPI packages.
Fix
Documented that mv-api is intended to run from the Pixi workspace.

13. Timestamp loader mutates cached stream names

Fixed

packages/mv-api/src/mv_api/data/synced_videos.py

Why it mattered
The method name sounded read-only even though it resets and repopulates ego/exo stream-name caches.
Fix
Updated the docstring to state the side effect explicitly.

14. Two hand bbox helpers could drift

Fixed

packages/mv-api/src/mv_api/multiview_pose_estimator.py

Why it mattered
The pipeline and tracker had nearly identical bbox logic with subtly different NaN behavior.
Fix
Added shared compute_square_bbox_from_uv; both call sites delegate to it.

15. Ego bbox helper rejected any NaN keypoint

Fixed

packages/mv-api/src/mv_api/api/full_exoego_pipeline.py

Why it mattered
One occluded fingertip could skip WiLor refinement for an otherwise usable hand.
Fix
The shared bbox helper filters finite rows and computes the box from the valid subset.
Test
Added a partially-NaN hand-keypoint test.

16. Group-level hand confidence gate needed intent

Documented

packages/mv-api/src/mv_api/api/full_exoego_pipeline.py

Assessment
The group gate is intentional for the Rerun skeleton visualization, so low-confidence hands disappear as a coherent unit.
Fix
Added a code comment documenting that behavior and replied on GitHub.

17. Duplicate frame timestamp helpers

Fixed

packages/mv-api/src/mv_api/api/full_exoego_pipeline.py

Why it mattered
Two FPS-to-timestamp implementations could drift; one already had validation the other lacked.
Fix
Promoted frame_timestamps_from_reader from the synced-video module and reused it in the pipeline.

18. RRD stats parser could silently accept changed CLI output

Fixed

packages/mv-api/src/mv_api/api/rerun_artifact_compare.py

Why it mattered
If rerun rrd stats changed its text format, both parsed maps could be empty and comparisons could pass vacuously.
Fix
Raise ValueError when the CLI succeeds but no overview or entity counts can be parsed.
Test
Added a fake successful stats output test that must fail parsing.
